# Guide utilisateur

1. Au premier lancement, créer le premier administrateur. Aucun mot de passe par défaut n'est fourni.
2. Se connecter avec ce compte, créer les catégories et les produits.
3. Initialiser les stocks dans l'écran Stocks.
4. Utiliser Nouvelle vente pour rechercher les produits, préparer le panier et choisir le paiement.
5. Les rapports, exports et sauvegardes sont accessibles à l'administrateur.

Les sauvegardes automatiques sont conservées dans `%LOCALAPPDATA%\MagasinGestion\Backups`. Une erreur d'impression ou d'export ne modifie jamais une vente déjà validée.
